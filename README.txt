ADÉE TIMER — application indépendante

Cette version est séparée de l’application Adée Mobilité.

Pour l’installer comme une vraie application sur Android, il faut héberger ce dossier sur une adresse HTTPS
(par exemple Vercel, Netlify ou GitHub Pages).

Une fois en ligne :
1. Ouvre l’adresse dans Chrome.
2. Touche ⋮.
3. Choisis « Installer l’application » ou « Ajouter à l’écran d’accueil ».
4. L’icône « Adée Timer » apparaîtra sur ton écran d’accueil.

Après une première ouverture en ligne, l’application peut fonctionner hors ligne grâce au service worker.
